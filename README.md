This repository is a static multi-page college website built using HTML, CSS, and JavaScript. It contains pages such as the homepage, chairperson and principal message sections, and a gallery showcasing college events and activities, all designed to present Edutek College as a modern educational institution. The project uses simple front-end files without any framework or backend, making it easy to run locally by opening the `index.html` file in a browser or serving the folder with a local web server. It includes shared styling in `style.css`, image popup behavior in `script.js`, and supporting image assets such as `chairperson.jpg`, `principal.jpg`, and event photos for the gallery. The project is suitable for a basic college landing page or informational website and can be extended with more sections like admissions, faculty, contact information, and course details.
